# Candle Bot

Simple 1-minute candlestick chart analyzer built with Vite, React, TypeScript, and Tailwind.

## Cara Menjalankan (Local)

```sh
npm install
npm run dev
```

Akses aplikasi di URL yang ditampilkan oleh Vite (biasanya `http://localhost:5173`).

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui
